# API Reference

The FastAPI backend connects all four modules. Full interactive docs are auto-generated by FastAPI — once the server is running, visit `http://127.0.0.1:8000/docs` for a live, testable interface. This file is a quick static reference alongside that.

## Running the API

```bash
uvicorn api.main:app --reload
```

## Updating this file

Whenever an endpoint's actual request/response shape is implemented, update its row here with the real Pydantic schema (from `api/schemas/`) instead of "TODO" — this is what the Visualizer and Validator read to know what to expect without asking you directly.
